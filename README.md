This is the version of the timetable based authentication system designed to work on x64 or x86 environments rather that on pi 
This project has backend, frontend and device
Backend - for managing and storing the student information and examination info such as timetable etc
Frontend - for registering the student info including their facial template of the student
Device - for scanning and authenticating the student during the examination process.
